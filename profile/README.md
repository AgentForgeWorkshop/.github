# AgentForge

**Hands-on Workshop on AI Agents as Scientific Research Assistants**
Nanyang Technological University, Singapore · 15–19 November 2026 · Sponsored by Schmidt Sciences

Everything we built during the week is public. Each repository states its own licence: mini_agent, agent-tutorial, Sanity, Resplandy and Judgment-Skill are MIT. For the others, please ask the authors before you reuse them.
Website: **https://agentforge.groundstate.sg/**

### Tutorials

- [Tutorials](https://github.com/AgentForgeWorkshop/Tutorials): slides for all five tutorials, and notebooks for four, several of which run in Colab.
- [agent-tutorial](https://github.com/Superionichuan/agent-tutorial): the mini_agent notebooks for Tutorials 1 and 2. They run in Colab in offline mode, with no API key.
- [mini_agent](https://github.com/Superionichuan/mini_agent): the small, complete AI agent from Tutorial 1, released as an open-source package (MIT licence).

### Hackathon projects

- [Sanity](https://github.com/AgentForgeWorkshop/sanity): a multi-agent checker that finds mathematical errors in papers. The language model proposes; a computer algebra system and Lean decide. [Live demo](https://ilkhamfy.github.io/sanity/demo.html)
- [Resplandy](https://github.com/rugphy-hub/resplandy): a multi-agent research-planning assistant: agents propose, code checks, you decide.
- [Think Twice](https://github.com/AgentForgeWorkshop/Trio-s-agent-Think-Twice): a brainstorming agent that helps you judge how novel a research idea is.
- [TripPlanner](https://github.com/AgentForgeWorkshop/TripPlanner): a multi-agent assistant for planning trips to academic conferences.

The organisers also published the Agent Skill they used to review the entries: [Judgment-Skill](https://github.com/AgentForgeWorkshop/Judgment-Skill).
